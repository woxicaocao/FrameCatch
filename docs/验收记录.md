## 1.4 记住配对与自动重连

验证日期：2026 年 11 月 16 日（北京时间）。

- 首次配对成功后软件保存随机令牌的 SHA256 校验值及自动连接设置；插件仅将随机本机令牌保存至受信任的本地存储。原始网站 Cookie 和媒体请求仍只在插件会话中保存，不写同步存储。
- 软件正常退出保留配对，下次启动自动恢复本机监听。插件打开时自动连接，软件未启动则等待并重试；Chrome 重启或扩展重新加载后无需重新输入配对码。
- “暂停自动连接”停止监听但保留配对；“忘记配对”撤销旧令牌并写空记录，不删除文件。保存失败或记录损坏会显示明确错误，不静默覆盖或宣称成功。
- 核心回归与新增真实 HTTP 配对测试通过，包括跨对象恢复、便携目录迁移、并发首配、退出/撤销竞态、损坏记录及写盘失败。扩展 29 项逻辑测试通过，包括离线后恢复、401 撤销、旧会话迁移、异步旧响应不覆盖新配对。
- 独立真实 Chrome 与桌面端到端测试通过：首次配对 → 退出软件并等待 → 重启软件自动连接 → 重启 Chrome 自动连接，媒体会话清空；重连后下载真实本地受限 MP4，双轨、时长、全片解码正常。界面“忘记配对”后旧令牌返回 401。
- 自动化仅使用测试配置预授权，不操作用户的 Chrome、真实登录资料或权限提示。首次升级到持久配对功能需要再配对一次；移动并保留同一便携数据目录可保留配对，全新数据目录则需首次配对。

- 新增 Chrome Manifest V3 助手及桌面配对窗口。用户主动启用当前标签页，选择完整媒体后发送到映取，分析完成后手动选择画质并下载。

- 用户实际反馈确认：Vimeo 在正常 Chrome 可播放，但 1.1 内置浏览器遭 Cloudflare 验证失败。内置浏览器对这类验证并不能保证兼容，因此增加免扩展的 Chrome 请求接力入口，而不是继续要求在失败的窗口中反复验证。
- 支持用户显式复制、粘贴单条 Chrome cURL 请求；软件仅解析文本，不执行命令，不扫描 Chrome 账号或 Cookie 数据库，不后台读取剪贴板。
- 87 项核心与安全测试通过，其中请求解析器新增 53 项：Chrome 当前及旧版 cmd、bash/ANSI-C 转义、签名保留、域限定 Cookie、危险参数与命令链拒绝等。
