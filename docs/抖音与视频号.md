# 抖音与视频号分享下载（1.5）

软件左侧新增“抖音 / 视频号”标签页，支持粘贴单条作品的完整分享文案、抖音短链、抖音作品网址或视频号分享短链。

## 使用

1. 点击“抖音 / 视频号”，粘贴分享内容。整段“复制打开抖音……”文案可直接粘贴，不必手工截网址。
2. 检查识别出的平台和作品网址，点击“分析分享内容”。`jingxuan?modal_id=…` 会转换成对应的单条抖音视频地址，作品编号全程保留为字符串。
3. 分析成功后核对标题和画质，点击下载。结果进入与工作台共用的下载队列和历史，完成后校验文件轨道及完整性。
4. 如果网页要求验证或分析未完成，可以使用“打开原网页”“浏览器辅助分析”或“连接浏览器插件”。插件只适用于能在正常浏览器实际播放的媒体。

每次处理一条作品。复制多条不同链接时会提示重新选择；不支持只有文字、没有网址的分享内容。清空或修改输入会使旧分析结果失效；取消会保留已下载文件。

## 抖音

支持 `v.douyin.com` 短链、`douyin.com/video/作品编号` 和含 `modal_id` 的精选页链接。普通解析入口可能要求当前浏览器会话；这不能直接理解为必须登录账号。

普通入口未取得作品时，1.5 会尝试软件自身的隔离网页会话，读取该作品正常返回的公开数据并选择完整 MP4，不读取已安装 Chrome 的账号资料。需要网站验证时不会自动完成验证；仍可改用可见浏览器辅助或 Chrome 插件。

原网页提供的可用媒体才能下载。最高可用 MP4 指当前取得的可下载完整资源，不能据此保证覆盖平台的所有编码或清晰度。图集、直播和账号主页不是本页的单条视频输入。

## 视频号

支持识别 `weixin.qq.com/sph/…` 分享链接。视频号的官方分享预览可能只给封面、标题和微信二维码，并未给网页提供视频数据。遇到这种情况，软件会明确说明“分享预览页尚未提供可下载的视频”，不会把封面当视频，也不会把作品误报成丢失。

若原网页只有“可扫码前往微信观看此内容”，需要在微信内观看；Chrome 插件不能捕获没有在 Chrome 中播放的媒体。软件当前不读取微信数据库、不安装 HTTPS 证书、不接管微信登录资料，也不使用第三方付费解析服务。

抖音初始 CLI 路径实际返回会话提示，不能把 HTTP 200 的验证脚本页算作解析成功。视频号 `stodownload` 请求在本例为 JPG 封面，不计为视频。真实报告位于项目 `.test-artifacts/douyin-real-*`、`douyin-browser-detail-*` 与 `wechat-real-*`，私有请求文件不应公开分享。

分享文案仅用于本机提取支持的网址，不作为命令执行，不整体写入任务状态或日志。分析及下载会向原平台与其 CDN 请求内容；浏览器辅助会话和捕获凭据仍仅保存在本机 `data`，请勿分享带登录态的完整便携目录。
