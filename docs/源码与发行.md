# 源码与便携发行包

源码仓库保存映取 FrameCatch 的应用源码、Chrome 浏览器助手、测试、构建脚本、依赖版本与校验清单、许可证和使用说明。

## 从源码开发

需要 Windows x64 和受支持的 Node.js 24 或更新版本。

```powershell
npm ci
npm run deps:prepare
npm run dev
```

`deps:prepare` 从组件官方来源下载构建所需的 yt-dlp、FFmpeg 和 Deno，验证校验值并准备随包许可证及相关源码。源码仓库不保存这些可执行文件、DLL 和缓存压缩包。

```powershell
npm run typecheck
npm test
npm run test:extension-unit
npm run package:portable
```

打包结果写入新的 `releases/build-时间戳/`，可交付文件为 `FrameCatch-版本-Windows-x64-portable.zip`。请完整解压后运行，不需要安装。

## 上传范围

以下文件仅保留在本机，不进入源码提交：

- `data`、`Downloads`、`work`、浏览器会话、Cookie、配对凭据和任务日志。
- 已解压的各版便携程序、下载的视频、调试截图和测试产物。
- `node_modules`、构建输出、组件缓存、可执行依赖和历史发行压缩包。
- 本机故障记录、环境变量文件和备份。

需要分发便携程序时，使用新构建的干净 ZIP 和同名 SHA256 校验文件作为发行附件。不要上传自己实际运行过、含 `data` 或 Cookie 的整套程序文件夹。

当前版本的视频号支持范围仍以 [抖音与视频号](抖音与视频号.md) 的实测说明为准；只提供微信二维码的分享预览不等于已支持下载。
