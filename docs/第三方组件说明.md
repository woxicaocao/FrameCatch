## 溯源和校验

出厂组件的下载 URL、官方校验文件 URL、下载包 SHA256、每个执行文件/DLL 的 SHA256 均保存在 `resources/dependencies.json`。源码归档的 SHA256 是对固定提交 HTTPS 下载内容的本地记录；GitHub 对这些自动生成的源码归档没有另行发布独立签名校验文件。

准备过程已核对二进制下载包的官方 SHA256；没有对 Windows Authenticode 或上游 GPG 签名作额外背书。不要把“有 SHA256”理解为软件受 Windows 商业代码签名证书签署。
